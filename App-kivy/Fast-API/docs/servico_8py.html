Função/Classe preprocess_audio. 

Pre-processa o áudio:
1. Converte para mono e 16kHz.
2. Aplica redução de ruído.
3. Normaliza o sinal.
4. Salva um WAV 16-bit PCM em UPLOAD_FOLDER.
